# Hi, I'm Karan Vashisht 😎

CSE student at **Delhi Technological University (DTU)**. I build full-stack apps and security tools for AI systems, with a focus on problems that matter in India. I'm looking for software engineering roles and internships.

## Projects

### [Agent-Firewall](https://github.com/KaranVashisht888/Agent-Firewall)
A local proxy that sits between an MCP client (Claude Desktop, Cursor, VS Code) and its MCP servers. It tracks the provenance of every piece of data flowing through the agent and blocks tool calls that violate a security policy. `Python`

### [UPI-SIM-Swap-Fraud-Detection-Engine](https://github.com/KaranVashisht888/UPI-SIM-Swap-Fraud-Detection-Engine)
A system that flags likely account-takeover and SIM-swap fraud in UPI payments, using device fingerprinting and behavioral graph analysis (sudden new devices, geo-velocity and similar signals). `Python`

### [Crop-Worth](https://github.com/KaranVashisht888/Crop-Worth)
A farmer-buyer produce marketplace with live bidding. `JavaScript`

### [Indian-Sign-Language-Interpreter](https://github.com/KaranVashisht888/Indian-Sign-Language-Interpreter)
An Indian Sign Language interpreter built to help bridge communication for people who cannot speak. `Python`
